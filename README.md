# Кабинет24

Сайт почасовой аренды кабинетов и залов в Минске: главная с каталогом, страницы помещений, правила аренды и документы PDF. Запись работает через Yclients.

## Требования и запуск

- PHP 8.2+ с расширениями `dom` и `mbstring`.
- Node.js 20+ нужен для сборки CSS и проверок; на сервере Node.js не требуется.

```sh
npm ci
npm run build
php -S 127.0.0.1:8000 scripts/router.php
```

Открыть http://127.0.0.1:8000. Готовый `assets/css/site.css` хранится в репозитории, поэтому страницы работают без CDN-компилятора Tailwind.

## Где менять содержимое

- `data/cabinets/*.json` - цены BYN, фотографии, вместимость, описания, порядок и доступность кабинетов. Для снятия с публикации установить `enabled: false`.
- `data/site.json` - время работы, условия отмены, общий адрес записи и пояснения к тарифам.
- `index.php`, `cabinet.php`, `rules.php` - страницы; `templates/` - общий подвал и внешние интеграции; `lib/site.php` - загрузка данных и общие функции.
- `styles/site.css`, `tailwind.config.cjs`, `assets/js/site.js` - оформление и поведение. После изменения классов выполнить `npm run build` и сохранить готовый CSS.

Если у кабинета пустой `booking_url`, кнопка записи использует общий адрес из `data/site.json`. Ссылка открывается и при недоступном скрипте виджета. Индивидуальная ссылка кабинета имеет приоритет.

Цены и групповые лимиты сверены с предоставленным прейскурантом с 1 мая 2026 года. Площадь в JSON хранится с исходной точностью, в PDF округляется до целых м², как в предоставленном документе. Для кабинета 43 подтверждена площадь 38 м². Вечерний тариф, не указанный отдельно, равен стандартному. «Счастливый час» действует по будням с 11:00 до 16:00; скидки не суммируются.

## Обновление PDF

После изменения цен или условий отмены обновить прейскурант и приложение к оферте:

```sh
python -m pip install -r scripts/requirements-documents.txt
python scripts/build-documents.py
python -m unittest discover -s tests -p "test_*.py"
```

Генератор использует JSON сайта, сохраняет первые шесть страниц действующей оферты, обновляет два пункта о поздней отмене и заменяет приложение с ценами. Требуется шрифт Arial в Windows или DejaVu Sans в Linux. После генерации визуально проверить оба PDF в `assets/`. Условия предоплаты и неявки без отмены сохраняются.

Фотографии хранить в WebP шириной 600 px, качество около 80%. Локальные оригиналы `*_full.*` не добавлять в Git; публикация их исключает.

## Проверки

```sh
npm run build
npm run check
php generate-sitemap.php
npm test
```

Проверяются данные и файлы, действующие и отключённые страницы, неверные URL, кнопки записи, часы работы, условия отмены, SEO-разметка, тарифы и карта сайта. `npm test` сам запускает временный PHP-сервер; нестандартный путь к PHP можно задать через `PHP_BINARY`. GitHub Actions запускает проверки на PHP 8.2 и 8.4 и контролирует актуальность собранного CSS.

## Публикация

cPanel Git использует `.cpanel.yml` и `scripts/deploy.sh`. Перед копированием проверяются синтаксис PHP, данные и обязательные файлы, затем строится sitemap. Публикуются страницы, общие функции, настройки, изображения, CSS, JavaScript, PDF и `.well-known`.

Путь по умолчанию: `/home/psychoan/domains/kabinet24.by/public_html/`; переопределяется переменной `DEPLOYPATH`. Скрипт не удаляет существующие файлы сервера. Для Apache нужен `mod_rewrite`, для Nginx есть пример `nginx.conf`.
